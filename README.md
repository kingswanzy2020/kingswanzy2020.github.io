# kahmedt case studies

Static, single-file HTML case studies. No build step, no framework.

- `index.html` — production-app-eks case study (first page; landing page and
  the other three case studies come next, once this format is approved)
- `.github/workflows/deploy.yml` — deploys on every push to `main` via
  GitHub Pages (Actions source, not the branch source)
- `add-real-icons.sh` — swaps the architecture diagram's placeholder icons
  for real vendor logos once you've dropped them into `assets/icons/`

Live at: https://kingswanzy2020.github.io/
